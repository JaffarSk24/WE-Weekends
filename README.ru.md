# WE Weekends

Бесплатная персональная рассылка дешёвых поездок в Telegram. Вы задаёте аэропорты вылета, страны, бюджеты на одного и на семью, рабочие дни, праздники и школьные каникулы и то, как часто получать сообщения. Каждый день сервис ищет прямые рейсы и жильё, оценивает каждый вариант по вашим правилам и присылает только то, что прошло отбор.

Настройки: https://jaffarsk24.github.io/WE-Weekends/?lang=ru · Бот: [@WEWeekendsBot](https://t.me/WEWeekendsBot)

## Только рекомендации

WE Weekends ничего не продаёт и не бронирует. Вы бронируете сами напрямую у авиакомпаний и отелей. Мы не турагентство и не получаем комиссий от партнёров. Цены берутся из открытых источников и могут измениться до бронирования.

## Устройство

- `web/`: страница настроек на чистых HTML, CSS и JavaScript без зависимостей, публикуется в GitHub Pages.
- `server/`: шлюз (Python, FastAPI, SQLite), который хранит настройки, пускает на сайт через Telegram-бота и ведёт поиск. Работает в Docker за nginx.

Поиск обходится без языковой модели, поэтому сервис стоит одинаково при любом числе пользователей: поиск идёт один раз на аэропорт вылета, а под каждого пользователя результаты фильтруются.
